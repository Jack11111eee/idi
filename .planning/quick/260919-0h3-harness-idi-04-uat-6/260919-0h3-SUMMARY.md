## Deviations from Plan

### 1. [Rule 3 - 阻塞] 浏览器改用 Playwright 自带 chromium,而非 `channel="chrome"`

- **Found during:** Task 1(切片首次运行)
- **Issue:** 计划的「必须用系统 Chrome」在两条理由上都已失效:
  (a) 「捆绑版 chromium 报 Executable doesn't exist at .../chromium-1243」—— **已失效**。
  本 venv 装的 playwright 1.63.0 正好对应 revision 1243,该目录已在
  `~/Library/Caches/ms-playwright/chromium-1243/chrome-mac-arm64`,零下载、arm64 原生。
  (b) `channel="chrome"` + `headless=True` 在本机 **CDP 永不连上,180s 超时挂死** ——
  本 venv 的 Python 是 x86_64(Rosetta),spawn 出来的系统 Chrome 跑 x86_64 切片,Chrome 自己打印
  "The use of Rosetta to run the x64 version of Chromium on Arm is neither tested nor maintained"。
  同机 `headless=False` 则 6.6s 成功。
- **Fix:** 默认 `--browser bundled`(自带 chromium,可无头、可无人值守);`--browser chrome` 保留,
  但强制有头。两条路径均实测通过(`bundle 0.5s / chrome 有头 6.6s`)。
- **Files modified:** `scripts/check-05-ui-uat.py`
- **Commit:** `6f52602`

### 2. [规格修正] box-shadow 断言改用语义解析,而非字面子串

- **Found during:** Task 2(item 2 首跑)
- **Issue:** 计划/UAT 写「computed box-shadow 含子串 `inset 3px 0 0 rgb(138, 101, 8)`」。
  实测 Chrome 的序列化是 **颜色在前、`inset` 在最后**:`rgb(138, 101, 8) 3px 0px 0px 0px inset`。
  字面子串逐字匹配为 False —— 这是浏览器序列化事实,不是产品缺陷。
- **Fix:** 断言改为解析 box-shadow 的语义分量(inset ✓ / x=3px / y=0 / blur=0 / spread=0 / 色=amber);
  UAT 字面子串的比对结果作为 INFO 打印在日志里,不隐藏。
- **Files modified:** `scripts/check-05-ui-uat.py`
- **Commit:** `6f52602`

### 3. [规格修正] `--item smoke` 断言「消费者→令牌接线」而非计划里的字面值

- **Found during:** Task 1
- **Issue:** 计划的 smoke 要求断言 `#state-badge` color = `rgb(31,99,189)` 并打印 PASS + exit 0。

  (接线正确即通过),并**额外打印** UAT 字面值的对照 INFO。**UAT 第 3 项仍逐字断言 `rgb(31,99,189)`
